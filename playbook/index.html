Power Pages UI Framework

A centralized, CDN-hosted UI framework for building consistent, scalable, and reusable user interfaces across all Power Pages portals. This playbook acts as the single source of truth for all UI components, patterns, and usage guidelines.

Why this framework exists

Power Pages development often suffers from duplicated UI work, inconsistent designs, and slow iteration cycles. This framework solves those problems by providing a standardized library of components that can be reused across portals without redeployment.

How it works

Components are configured using HTML data-attributes, loaded via CDN-hosted JavaScript and CSS, and rendered dynamically inside Power Pages. No inline JavaScript is required, making it fully CSP-compliant and safe for enterprise use.
