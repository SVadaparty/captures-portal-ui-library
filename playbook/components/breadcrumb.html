How to use Breadcrumbs


      
<nav
  data-pp-breadcrumb
  data-items="Home, Products, Electronics, Mobile"
  data-links="/, /products, /electronics,"
  data-icons="🏠, 📦, ⚡, 📱"
  data-separator="/">
</nav>
      


      
Supported Attributes

      

        
AttributeDescription

        
data-itemsBreadcrumb labels

        
data-linksLinks for each item

        
data-iconsIcons per item (optional)

        
data-separatorSeparator character

        
data-text-colorDefault text color

        
data-link-colorLink color

        
data-active-colorActive item color

        
data-font-sizeFont size
