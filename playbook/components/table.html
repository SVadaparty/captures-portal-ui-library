Power Pages Table

How to use this Table in Power Pages

This component is rendered entirely through HTML attributes. No JavaScript is required in Power Pages.

Basic Example

<div
  data-pp-table
  data-datasource="usersData">
</div>

With Search & Pagination

<div
  data-pp-table
  data-datasource="usersData"
  data-search="true"
  data-page-size="10">
</div>

Supported Attributes

AttributeDescription
data-datasourceGlobal JS array name
data-searchEnable search box
data-filterEnable column filter
data-search-placeholderSearch input placeholder
data-filter-placeholderFilter dropdown placeholder
data-page-sizeRows per page
data-widthTable width
data-font-familyFont family
data-font-sizeFont size
data-text-colorText color
data-border-colorBorder color
data-header-bgHeader background
data-header-text-colorHeader text color
data-row-hover-bgRow hover background
data-sticky-headerSticky header
data-column-toggleShow/hide columns
