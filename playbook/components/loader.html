How to use Loader


      
<div
  data-pp-loader
  data-text="Loading..."
  data-size="48px"
  data-color="#2563eb"
  data-bgcolor="#e5e7eb"
  data-align="center">
</div>
      


      
Supported Attributes

      

        

          Attribute
          Description
        

        

          data-text
          Loader label text
        

        

          data-size
          Spinner size (px / rem)
        

        

          data-color
          Spinner color
        

        

          data-bgcolor
          Spinner background ring color
        

        

          data-align
          flex-start / center / flex-end
