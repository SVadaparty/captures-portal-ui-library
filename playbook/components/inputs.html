Power Pages Input

How to use this Input

Inputs are rendered using HTML attributes and your CDN framework. No JavaScript is required in Power Pages.

Basic Input

<input data-pp-input data-placeholder="Enter name">

Email Input

<input
  data-pp-input
  data-type="email"
  data-placeholder="Enter email">

Custom Width & Color

<input
  data-pp-input
  data-width="400px"
  data-bgcolor="#f9fafb"
  data-bordercolor="#3b82f6">

Supported Attributes

Attribute Description
data-type text, email, password, number
data-placeholder Placeholder text
data-width Input width
data-height Input height
data-color Text color
data-bgcolor Background color
data-bordercolor Border color
data-onchange JS function name for change

All attributes are optional. Defaults are applied automatically by the CDN framework.
