How to use Datepicker



<input
  data-pp-datepicker
  data-width="260px"
  data-height="40px"
  data-color="#111827"
  data-bgcolor="#ffffff"
  data-bordercolor="#d1d5db"
  data-onchange="onDateChange">



      
Supported Attributes

      

        

          Attribute
          Description
        

        

          data-width
          Input width
        

        

          data-height
          Input height
        

        

          data-color
          Text color
        

        

          data-bgcolor
          Background color
        

        

          data-bordercolor
          Border color
        

        

          data-onchange
          JS callback function
        

      


      

        Dates before today are automatically disabled.
