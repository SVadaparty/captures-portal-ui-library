How to use Tabs


      
<div
  data-pp-tabs
  data-tabs="Overview, Details, Settings"
  data-active="0"
  data-active-bg-style="underline"
  data-onselect="onTabSelect">
</div>
      


      
Supported Attributes

      

        
AttributeDescription

        
data-tabsComma separated tab labels

        
data-activeActive tab index (0-based)

        
data-active-bg-styleunderline or block

        
data-text-colorDefault tab text color

        
data-active-colorActive tab text color

        
data-active-bgActive tab background / underline

        
data-hover-colorHover text color

        
data-onselectJS function name
